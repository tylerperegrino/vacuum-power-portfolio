# +1 Vacuum Power

A Roblox game where players use a vacuum to collect resources,
hatch eggs, gain currency, fight bosses and unlock new areas.

## My contributions
- Built the backend system for saving and loading player progress.
- Added server-side purchase validation and atomic balance updates.
- Designed UI assets in Adobe Illustrator and implemented the
  frontend in Luau.
- Tested saving and loading across sessions with 50+ playtesters.

## Technologies
Luau, Roblox Studio, Roblox DataStores, ProfileStore
Adobe Illustrator.
